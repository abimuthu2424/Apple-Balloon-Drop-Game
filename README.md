# Apple Balloon Drop

A Python-based grid simulation project where users can drop apples and balloons into selected columns.

## Features Implemented
- Dynamic row and column creation.
- 2D matrix representation.
- Interactive menu for object selection.
- Apple and balloon placement.
- Bottom-to-top object placement.
- Basic input validation.

## Technologies Used
- Python
- 2D Lists
- Functions
- Loops and Conditional Statements
- Exception Handling
